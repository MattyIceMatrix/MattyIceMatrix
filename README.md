## `$ whoami`

Edge AI and AI-governance engineer in Kaiserslautern, Germany. Eight years U.S. Army, now enterprise IT by day and AI systems the rest of the time.

I build in one direction: **AI you can hold accountable.** As agents start touching real infrastructure, the hard problem stops being capability and becomes evidence — can you prove what a system was allowed to do, what it actually did, and that a human stayed in the loop? Everything below is some part of that answer, or the edge hardware it has to run on when the network is gone.
